Small `radius-sm` labels for roles, categories and status. Three forms:

- **Neutral** — `surface-sunken` fill, `ink-secondary` text, `border-subtle` outline. Default category tag.
- **Accent** — `accent-soft` fill, `accent-strong` text, no border. Reserved for the one thing that should stand out (e.g. "Mentor").
- **Status** (success / warning / error) — a neutral tag with a small colored dot and matching text color, so status reads through color *and* shape, not color alone.
