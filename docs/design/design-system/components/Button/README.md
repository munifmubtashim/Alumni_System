Three weights of emphasis, never more than one primary button per view.

- **Primary** — solid `accent` fill, `accent-ink` text. The one call-to-action on a screen (Join network, Save profile).
- **Secondary** — `surface-raised` with a `border-strong` outline. Supporting actions alongside a primary.
- **Ghost** — text-only, no border. Low-emphasis actions (Cancel, Dismiss) and inline actions in tables.

All variants: `radius-md`, `space-3`/`space-4` padding, `label` type style. Hover deepens the border/fill toward `accent-strong`; there is no shadow or glow — only a border and fill-color change.
